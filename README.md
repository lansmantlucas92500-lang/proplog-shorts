# PropLog — shorts

Vidéos courtes (Reels) de [PropLog](https://proplog.fr), journal de trading pour traders prop firm
futures. Ce dépôt public sert uniquement à héberger les vidéos pour leur programmation dans Metricool.

- `videos/AAAA-MM-JJ-NN-sujet.mp4` : un Reel par jour, du 2 novembre au 2 décembre 2026, publié à 8 h
  (Europe/Paris), 1080 × 1920, voix off française de synthèse (Piper, voix `fr_FR-tom-medium`).
- Les chiffres montrés viennent de la démo de proplog.fr : données fictives, signalées à l'écran.

Contenu éducatif : aucune promesse de résultat, aucun conseil en investissement. Le trading comporte
un risque de perte en capital. Code affilié : LUCAS chez phidiaspropfirm.com.
